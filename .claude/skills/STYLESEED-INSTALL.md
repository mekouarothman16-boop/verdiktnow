# StyleSeed — vendored install (skills only)

Source: https://github.com/bitjaru/styleseed (MIT), version 4.1.0.

Installed 2026-08-24 by copying `engine/.claude/skills/*` (23 skills) and
`engine/*` (reference docs: DESIGN-LANGUAGE.md, RULESETS.md, BRAND-RECIPES.md,
PALETTE-RECIPES.md, tokens, scaffold, etc.) verbatim into this folder, so the
skills' internal `built-in:engine/<file>` references resolve as
`.claude/skills/engine/<file>` relative to this directory.

Deliberately skipped: the documented `npx skills add` installer, and the
CLAUDE.md/AGENTS.md rule injection it also performs. This project's
`AGENTS.md` is regenerated by `next dev` on every start (see
`node_modules/next/dist/server/lib/generate-agent-files.js`), so any content
StyleSeed added there would be silently overwritten. If full CLAUDE.md/AGENTS.md
integration is wanted later, read `engine/UPDATE.md` and hand-merge only the
CLAUDE.md portion, or accept that the AGENTS.md portion needs re-adding after
every dev-server restart.

Entry points: `/styleseed` (router), `/ss-setup` (first-time project setup),
`/ss-build`, `/ss-audit`, `/ss-score`, `/ss-verify`, etc. — see
`engine/CLAUDE.md` for the full skill list and workflow.

To update: re-clone the source repo and re-copy `engine/.claude/skills/*` and
`engine/*` (excluding `engine/.claude`) over this folder, or follow `engine/UPDATE.md`.
